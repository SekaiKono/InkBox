# 墨盒InkBox
一款仿Vscode的雙屏Markdown編輯器，PWA全平台通用(大概)
其實是作者自己沒找到全平台通用的雙屏編輯器才自己做的
由DeepSeek~~藍色大肥魚~~製作
可離線使用
快捷鍵：
- Crtl+B **粗體**
- Crtl+I *斜體*
- Crtl+S 保存 (需要使用"打開資料夾"，且只有部分瀏覽器支持)

目前導出pdf功能有點問題，~~但作者也沒再用所以懶得修(???)~~

預計加入功能
- 字體縮放
- 表格插入
- 導出pdf功能修復
